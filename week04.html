3  추리통계를 위한 개념

3.1 정규분포 (Normal Distribution)

3.1.1 정규분포란 무엇인가?

정규분포(normal distribution)는 좌우가 완벽하게 대칭인 종 모양(bell-shaped) 곡선이다. 자연 현상이나 사회 현상에서 측정되는 수많은 변수들이 이 모양을 따른다.

  • 표기: \(Y \sim N(\mu, \sigma^2)\) — 평균 \(\mu\), 분산 \(\sigma^2\)인 정규분포
  • 평균이 분포의 중심 위치를, 표준편차가 분포의 퍼짐 정도를 결정
  • 평균과 표준편차 두 값만 알면 분포의 모양이 완전히 정해짐
Note

IQ 점수, 키, 체중, 학업성취도, 심리검사 점수 등 심리·교육 분야의 많은 변수들은 정규분포에 근사한다. 이 가정이 성립할 때 다양한 통계적 추론(검정, 신뢰구간 등)이 가능해진다.

  • 우리나라 성인 남성의 키는 평균 174cm, 표준편차 약 6cm인 정규분포를 따름
  • 표준화 심리검사(예: MMPI) 점수는 평균 50, 표준편차 10인 정규분포(T점수)로 변환하여 사용

3.1.2 표준편차 구간별 포함 확률 — “68-95-99 법칙”

정규분포에서 평균을 중심으로 표준편차 몇 배 범위 안에 전체의 몇 %가 포함되는지는 고정되어 있다.

범위 포함 비율 쉽게 기억
\(\mu \pm 1\sigma\) 68.26% 약 2/3
\(\mu \pm 2\sigma\) 95.44% 거의 대부분
\(\mu \pm 3\sigma\) 99.72% 사실상 전부

예시: 평균 100, 표준편차 15인 IQ 분포라면

  • 85~115(\(\pm1\sigma\)) 사이에 전체 인구의 약 68% 해당
  • 70~130(\(\pm2\sigma\)) 사이에 약 95% 해당
  • 55~145(\(\pm3\sigma\)) 사이에 약 99.7% 해당
  • IQ 130 이상(상위 약 2.3%)이면 통계적으로 매우 드문 경우임을 알 수 있음
Note

평균에서 \(\pm2\sigma\)(정확히는 \(\pm1.96\sigma\)) 이상 떨어진 값은 전체의 약 5%에 불과하다. 이것이 바로 통계검정에서 유의수준 5% 기준을 설정하는 근거가 된다.

3.1.3 표준정규분포와 z점수

서로 다른 척도의 정규분포들을 비교하려면 공통 기준으로 변환해야 한다. 이것이 표준화(standardization)다.

표준정규분포(standard normal distribution)는 평균 = 0, 표준편차 = 1로 변환한 특수한 정규분포이다. z분포라고도 하며, 표준정규분포표(z표)가 만들어져 있어 확률 계산에 활용된다.

z점수(표준점수) 공식

\[z = \frac{X - \bar{X}}{S_X}\]

X는 관측값, \(\bar X\)는 평균, \(S_X\)는 표준편차이다. z점수는 “이 값이 평균보다 표준편차 몇 개만큼 위/아래에 있는가”를 나타낸다.

해석 예시:

  • z = +1.5 → 평균보다 1.5 표준편차 위 → 상위 약 6.7%
  • z = -2.0 → 평균보다 2 표준편차 아래 → 하위 약 2.3%
  • z = 0 → 평균과 동일

실제 예시: 어떤 학생의 수학 점수가 80점이고, 반 평균은 70점, 표준편차는 10점이라면

\[z = \frac{80-70}{10} = 1.0\]

이 학생은 반에서 평균보다 1 표준편차 위에 위치(상위 약 16%)한다.

3.1.4 표준정규분포표 활용 — 확률 구하기

z점수를 구한 후 표준정규분포표(z표)를 이용하면 특정 값 이하/이상의 확률을 구할 수 있다.

문제 계산 방법 결과
z < 1인 확률 (z=1 이하) z표에서 직접 읽기 0.8413 (84.13%)
z > 1인 확률 (z=1 초과) 1 − 0.8413 0.1587 (15.87%)
z < −1 또는 z > 1인 확률 (양쪽 꼬리) (1 − 0.8413) × 2 0.3174 (31.74%)
중간 95%를 포함하는 z 범위 하위 2.5% ~ 상위 2.5% z = ±1.96

“z = 1보다 작을 확률이 84.13%”란, 전체 중 84.13%의 사람들이 이 학생보다 점수가 낮다는 뜻이다.

Note

z = ±1.96은 추리통계 전반에서 반복적으로 등장하는 핵심 임계값이므로 반드시 기억해 두어야 한다.

3.2 표집분포 (Sampling Distribution)

3.2.1 표집분포의 개념

우리는 표본 하나로 모집단을 추론하는데, 표본은 매번 다를 수 있다. 이 불확실성을 어떻게 다룰까?

표집분포(sampling distribution)란, 같은 모집단에서 동일한 크기(n)의 표본을 무한히 반복 추출했을 때, 각 표본에서 구한 통계치들(예: 표본평균)이 이루는 분포이다.

직관적 비유: 전국 고등학생의 수학 성적(모집단)에서 50명씩 표본을 뽑는 실험을 1,000번 반복한다고 상상해보자.

  • 1번째 표본: 표본평균 = 68점
  • 2번째 표본: 표본평균 = 71점
  • 3번째 표본: 표본평균 = 69점
  • … (1,000번 반복)

이 1,000개의 표본평균들이 이루는 분포가 평균의 표집분포이다.

Note

표집분포는 ’표본 내 개인들의 분포’가 아니라, ’표본통계치(표본평균 등)의 분포’이다.

3.2.2 표준오차 (Standard Error)

표준오차(SE)는 표집분포의 표준편차다. 즉, 표본통계치가 모수치로부터 평균적으로 얼마나 벗어나는지를 나타낸다.

\[SE = \frac{\sigma}{\sqrt{n}}\]

\(\sigma\)는 모집단 표준편차, n은 표본크기이다.

표준편차 vs. 표준오차 비교:

개념 무엇의 퍼짐? 의미
표준편차(SD) 개인 점수들의 퍼짐 개인 간 차이의 크기
표준오차(SE) 표본평균들의 퍼짐 표본평균이 모평균으로부터 벗어나는 정도

예시: 모집단 표준편차 \(\sigma = 10\), 표본크기 n = 100이라면

\[SE = \frac{10}{\sqrt{100}} = 1.0\]

100명짜리 표본들의 평균은 모집단 평균으로부터 평균적으로 약 1점 정도 벗어난다. 표본크기가 4배 늘면 표준오차는 절반으로 줄어든다(n=100 → n=400: SE = 10/20 = 0.5). 이것이 표본이 클수록 추정이 더 정확해지는 이유다.

3.2.3 중심극한정리 (Central Limit Theorem)

Note

원래 모집단의 분포와 관계없이, 표본평균들의 분포는 표본의 크기(n)가 커짐에 따라 정규분포에 근접한다. 이때 평균은 \(\mu\)이고, 분산은 \(\sigma^2/n\)이다.

표기: \(\bar Y \sim N(\mu, \sigma^2/n)\)

이것이 왜 혁명적인가? 모집단이 정규분포가 아니어도(치우친 분포, 이분 분포 등) 상관없다. 표본이 충분히 크면(n ≥ 30) 표본평균들은 항상 정규분포를 따른다. 이는 정규분포 기반의 통계 공식들을 폭넓게 적용할 수 있게 해주는 이론적 토대가 된다.

예시: 소득 분포는 심하게 오른쪽으로 치우쳐 있다(일부 고소득자 때문에). 그러나 이 모집단에서 n=50명씩 표본을 반복 추출하면, 표본평균들의 분포는 정규분포에 가까워진다. 이것이 소득 연구에서도 정규분포 기반의 t검정 등을 적용할 수 있는 근거가 된다.

평균의 표집분포 특성 요약:

속성 내용
분포의 평균 표본평균들의 평균 = 모집단의 평균(\(\mu\))
분포의 표준편차 표준오차(\(SE=\sigma/\sqrt n\))
분포의 형태 모집단이 정규분포 → 항상 정규분포 / 모집단 분포 미상 → n ≥ 30이면 정규분포 근사

3.2.4 표집분포와 가설검정의 연결

표집분포는 가설검정에서 “내 표본 결과가 우연인가, 진짜인가”를 판단하는 기준이 된다.

  • 채택역: 표집분포의 중앙 95% 범위 → 이 범위 안의 값은 “우연히 나올 수 있는 값”으로 판단
  • 기각역: 양쪽 끝 5% → 이 범위의 값은 “우연이라고 보기 어렵다”고 판단 → 영가설 기각
  • 임계치(critical value): z = ±1.96 (유의수준 5% 양측검정 기준)

3.3 통계적 가설검정 (Statistical Hypothesis Testing)

3.3.1 가설검정이 필요한 이유

핵심 문제는, 표본에서 관찰된 차이가 진짜 차이(모집단 수준의 차이)인지, 우연에 의한 표본 오차인지 어떻게 구별하는가이다.

예시: 멀티미디어 교수법을 적용한 학급(50명)과 전통 교수법을 적용한 학급(50명)의 기말고사 평균 점수 차이가 2점이었다. 이 2점 차이는 (A) 우연히 이 표본에서만 나타난 것일 수도, (B) 실제로 교수법에 따른 효과일 수도 있다. 통계적 가설검정은 A와 B 중 어느 쪽이 더 타당한지 확률적으로 판단하는 절차이다.

3.3.2 영가설과 대립가설

영가설 (\(H_0\)) 대립가설 (\(H_A\) 또는 \(H_1\))
내용 “차이가 없다”, “효과가 없다” “차이가 있다”, “효과가 있다”
역할 검정이 기각하려는 가설 연구자가 증명하고 싶은 가설
특징 기준값과 같다고 가정 \(H_0\) 기각 시 간접적으로 지지됨

예시 — 상담 프로그램 효과 연구:

  • \(H_0\): 집단상담 프로그램을 받은 집단과 받지 않은 집단의 우울 점수 평균은 차이가 없다
  • \(H_A\): 집단상담 프로그램을 받은 집단과 받지 않은 집단의 우울 점수 평균은 차이가 있다
Note

통계적 검정은 대립가설을 직접 증명하지 않는다. 영가설이 참이라면 이런 결과가 나올 확률이 매우 낮다는 것을 보임으로써, 간접적으로 대립가설을 지지한다. 이는 “피의자의 무죄를 추정하다가, 증거가 충분하면 유죄를 선언하는” 법적 추론과 유사하다.

3.3.3 가설검정에서의 오류

가설검정은 확률적 판단이므로 항상 오류 가능성이 있다.

\(H_0\)가 실제로 참 \(H_A\)가 실제로 참
\(H_0\) 수용 올바른 결정 (1−α) 제2종 오류 (β)
\(H_0\) 기각 제1종 오류 (α) 올바른 결정 (통계적 검정력, 1−β)

제1종 오류(Type I error, α): 영가설이 참인데 기각하는 오류. “없는 효과를 있다고 잘못 결론”하는 것이다. 예: 실제로는 프로그램 효과가 없는데, “효과가 있다”고 결론 내림. α = 0.05로 설정하면 이런 오류를 범할 확률을 5% 이하로 통제하는 것이다.

제2종 오류(Type II error, β): 대립가설이 참인데 영가설을 수용하는 오류. “있는 효과를 발견하지 못함”이다. 예: 실제로 프로그램 효과가 있는데, “효과 없음”으로 결론 내림. 표본이 작을수록 발생 가능성이 높아진다.

통계적 검정력(statistical power, 1−β): 실제로 효과가 있을 때 그것을 탐지할 확률이다. 통상 0.80(80%) 이상이 권장된다. 표본크기 ↑, 효과크기 ↑, α ↑ → 검정력 ↑.

Note

검정력이 낮으면 실제로 효과 있는 치료 프로그램도 “효과 없음”으로 결론 날 수 있다. 이것이 사전에 표본크기 계산(표본 수 계획)이 중요한 이유다.

3.3.4 유의확률(p-value)과 유의수준(α)

유의확률(p-value)이란, 영가설이 참이라고 가정했을 때, 내가 표본에서 관찰한 것만큼 극단적인(또는 그 이상으로 극단적인) 결과가 나올 확률이다.

p = 0.03이라면 → “영가설이 맞는 세상에서 이런 결과가 나올 확률은 3%밖에 안 된다” → 영가설이 틀렸을 가능성이 높다 → 영가설 기각.

Note

흔한 오해 주의

  • “p = 0.03이면 영가설이 참일 확률이 3%다” → 틀린 해석
  • “영가설이 참이라는 가정 하에, 이런 데이터가 관찰될 확률이 3%다” → 올바른 해석

유의수준(α)은 연구자가 사전에 정하는 기준선으로, “p가 이 값보다 낮으면 영가설을 기각하겠다”는 제1종 오류의 최대 허용수준이다. 사회과학/교육학에서 통상 α = 0.05를 사용한다.

의사결정 원칙:

  • p < α(0.05) → 영가설 기각, 대립가설 채택 → “통계적으로 유의하다”
  • p ≥ α(0.05) → 영가설 기각 실패 → “통계적으로 유의하지 않다”

3.3.5 가설검정 결과 해석 및 표기

p값 범위 해석 논문 표기
p ≥ 0.05 통계적으로 유의한 차이(효과)가 없다 (표기 없음)
0.01 ≤ p < 0.05 통계적으로 유의한 차이(효과)가 있다 *
0.001 ≤ p < 0.01 통계적으로 유의한 차이(효과)가 있다 **
p < 0.001 통계적으로 유의한 차이(효과)가 있다 ***

논문 결과 기술 예시: “집단상담 프로그램 참여 집단(M=45.2)은 통제 집단(M=52.8)에 비해 우울 점수가 유의하게 낮았다, t(98) = 3.12, p = .002.” p = .002 < .05이므로 **로 표기, “통계적으로 유의한 차이가 있다”고 해석한다.

Note

“p ≥ 0.05”는 “차이가 없음을 증명”한 것이 아니다. “모집단에서 차이가 있다는 충분한 증거를 확보하지 못했다”는 의미다. 표본이 너무 작거나, 효과크기가 작을 때도 p ≥ 0.05가 나올 수 있다.

3.3.6 가설검정의 절차

  1. 가설 수립 및 유의수준 결정: 영가설(\(H_0\))과 대립가설(\(H_A\)) 설정, 유의수준 결정(통상 α = 0.05)
  2. 검정통계량 계산 및 유의확률 산출: 표본 자료로 검정통계량(test statistic; 영가설이 참일 때 알려진 분포를 따르는 통계량 — z, t, F, \(\chi^2\) 등)을 계산하고 해당 분포에서 유의확률(p-value) 확인
  3. 의사결정 (영가설 기각 여부): 검정통계량이 기각역에 속하는지 확인(예: |z| > 1.96)하거나, p < 0.05이면 영가설 기각, 대립가설 채택

3.3.7 실습 예제 — 단계별 풀이

문제: 전국 중학생의 연간 봉사활동 시간 평균이 20시간과 차이가 있는지 검정하려 한다. 100명을 표본 추출했더니 표본 평균이 21시간이었다. 전국 중학생의 봉사활동 시간 표준편차는 5시간으로 알려져 있다. 유의수준 0.05에서 검정하시오.

Step 1. 가설 설정

  • \(H_0\): 전국 중학생의 연간 봉사활동 시간의 평균 = 20시간 (차이 없음)
  • \(H_A\): 전국 중학생의 연간 봉사활동 시간의 평균 ≠ 20시간 (차이 있음, 양측검정)
  • 유의수준: α = 0.05

Step 2. 표집분포 확인

영가설이 참일 때 표본평균의 표집분포: \(\bar Y \sim N(20, 5^2/100)\). 표준오차: \(SE = 5/\sqrt{100} = 0.5\)

Step 3. 검정통계량 계산

\[z = \frac{\bar{Y} - \mu_0}{SE} = \frac{21 - 20}{0.5} = 2.0\]

Step 4. 의사결정

z = 2.0 > 임계치 1.96 → 기각역에 해당. 또는 z = 2.0에 해당하는 양측 p-value ≈ 0.046 < 0.05 → 영가설 기각

Step 5. 결론 기술

“전국 중학생의 연간 봉사활동 시간의 평균은 20시간과 통계적으로 유의한 차이가 있는 것으로 나타났다 (z = 2.0, p = .046).”

3.4 핵심 요약

  1. 정규분포: 좌우대칭의 종 모양 분포. 평균·표준편차로 완전히 정의됨. z점수로 표준화하면 어떤 정규분포든 표준정규분포로 변환 가능하며, 확률 계산이 가능해짐
  2. 표집분포: 표본통계치(예: 표본평균)들이 이루는 분포. 중심극한정리에 의해 n ≥ 30이면 모집단 분포에 관계없이 정규분포에 근사. 표준오차(\(SE=\sigma/\sqrt n\))는 추정 정확도의 척도 — 표본이 클수록 SE 감소
  3. 통계적 가설검정: 표본 결과가 우연인지 실제 효과인지를 확률로 판단하는 절차. 유의확률(p-value)이 유의수준(α = 0.05)보다 낮으면 영가설 기각 → “통계적으로 유의한 차이가 있다”고 결론
