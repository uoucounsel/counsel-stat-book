4  t검정

4.1 z검정의 한계와 t검정의 필요성

4.1.1 z검정이란?

표본평균이 특정 모집단 평균과 다른지 검정할 때, z분포를 활용하는 방법이다.

예시: 전국 중학생의 연간 봉사활동 시간 평균이 20시간과 차이가 있는지 검정하려 한다. 100명을 표본 추출했더니 표본 평균이 21시간이었다.

z검정의 공식:

\[z = \frac{\bar{Y} - \mu}{\sigma / \sqrt{N}}\]

이 공식에서 분모의 σ는 모집단의 표준편차다.

4.1.2 z검정의 결정적 문제

z검정을 하려면 모집단의 표준편차(σ)를 미리 알고 있어야 한다. 그런데 현실에서 모집단의 표준편차를 정확히 아는 경우는 극히 드물다. 봉사활동 예시에서 “전국 중학생들의 봉사활동 시간 표준편차는 5시간”이라는 정보가 주어지지 않는다면 z검정을 쓸 수 없다.

Note

모집단 분산을 모르는 현실적 상황에서는 z검정이 비현실적이다.

4.2 z검정 vs t검정: 무엇이 다른가?

\[z = \frac{\bar{Y} - \mu}{\sigma / \sqrt{N}} \quad \text{(모집단 표준편차 사용)}\]

\[t = \frac{\bar{Y} - \mu}{S / \sqrt{N}} \quad \text{(표본 표준편차 사용)}\]

핵심 차이는 분모에 들어가는 값이다.

  • z검정: σ (모집단 표준편차, 이미 알고 있음)
  • t검정: S (표본 표준편차, 데이터에서 계산)

모집단 표준편차를 모를 때, 표본에서 계산한 표준편차(S)로 추정한다. 이것이 t검정이다. “전국 평균 키를 모르지만, 내가 조사한 100명의 표준편차로 추정해서 검정하겠다”는 것이 직관적 이해이다.

4.3 t분포(t-distribution)

모집단 표준편차 대신 표본 표준편차를 사용하면, 검정통계량의 분포가 달라진다.

4.3.1 t분포의 특징

  • 0을 중심으로 좌우대칭 (정규분포와 동일)
  • 정규분포보다 봉우리가 낮고 양쪽 꼬리가 두꺼움 (표본 표준편차로 추정하는 데서 오는 불확실성 때문)
  • 자유도(df, degrees of freedom)에 따라 모양이 달라짐

4.3.2 자유도(df)란?

단일표본 t검정에서: df = N − 1. 예를 들어, 9명의 데이터로 평균을 구했다면 df = 8이다. 평균이 정해지면, 나머지 값 중 하나는 자동으로 결정된다. “자유롭게 변할 수 있는 값의 수”가 곧 자유도다.

4.3.3 자유도와 t분포의 관계

자유도(df) t분포의 모양
작을수록 꼬리가 더 두꺼워짐 (불확실성 ↑)
df = 30 이상 z분포에 근사
df = ∞ z분포와 동일

표본이 클수록 표본 표준편차가 모집단 표준편차에 가까워지므로, t분포도 z분포에 가까워진다.

4.4 평균 검정 방법 선택 기준

어떤 상황에서 z검정을, 어떤 상황에서 t검정을 쓸까?

  • 모집단이 정규분포를 따르고, 모집단 분산을 알고 있다면 → z검정
  • 모집단이 정규분포를 따르지만, 모집단 분산을 모른다면 → t검정 (대부분의 현실)
  • 모집단 분포가 불확실해도 n ≥ 30이면(중심극한정리) → z검정 또는 t검정 (거의 동일)
Note

실제 연구에서는 대부분 t검정을 사용한다.

4.5 t검정의 종류

비교하는 평균의 수에 따라 달라진다.

비교 평균 수 방법
1개 단일표본 t검정 (one sample t-test)
2개 (짝지어진 자료) 대응표본 t검정 (paired samples t-test)
2개 (독립된 집단) 독립표본 t검정 (independent samples t-test)
3개 이상 분산분석(ANOVA)

4.5.1 t검정의 기본 가정

  1. 정규성 가정: 검정하려는 변수가 모집단에서 정규분포를 따라야 함. 변수는 연속형이어야 하며, 히스토그램, Q-Q plot, 왜도/첨도, Shapiro-Wilk test로 확인
  2. 등분산 가정 (독립표본 t검정에만 해당): 두 집단의 분산이 모집단에서 동일해야 함. Levene’s test로 확인

4.6 단일표본 t검정 (One Sample t-test)

단일표본 t검정은 하나의 표본에서 계산한 평균이, 이론적으로 설정한 기준값과 차이가 있는지 검정하는 방법이다.

  • 예시 1: 중학생의 연간 봉사활동 시간이 교육청 권장기준 20시간과 차이가 있는지 검정
  • 예시 2: 상담 프로그램 참여자의 자기효능감 평균이 표준화 검사의 규준점수 3점(보통)과 다른지 검정

4.6.1 가설 설정

연구 장면 예시: 상담 전공 대학원생 A는 자신이 재학 중인 대학교 학생들의 학교만족도를 조사하고자 한다. 대학교 학생들 중 9명을 무선표집하여 5점 만점의 학교만족도 척도(연속적 점수)를 조사했더니, 평균 3.5점, 표준편차 0.75점이었다. A대학교 전체 학생의 학교만족도 평균이 3점(보통)과 차이가 있는지 유의수준 .05에서 검정하고자 한다.

  • 영가설(\(H_0\)): 모집단에서 학교만족도 평균이 3점과 같다 (\(\mu = 3\))
  • 대립가설(\(H_A\)): 모집단에서 학교만족도 평균이 3점과 차이가 있다 (\(\mu \neq 3\))

이 가설은 양방검정(two-tailed)이다. 방향을 특정하지 않고 “다르다”고 주장하기 때문이다.

4.6.2 검정통계량

\[t = \frac{\bar{Y} - \mu_0}{S_Y / \sqrt{N}}\]

\(\bar Y\)는 표본평균, \(\mu_0\)는 영가설이 참일 때 모집단 평균(비교 기준값), \(S_Y\)는 표본 표준편차, N은 표본 크기이다. 자유도는 df = N − 1이며, 이 t값은 자유도가 N−1인 t분포를 따른다.

t값의 의미는 “표본평균이 영가설에서의 기대값으로부터, 표준오차(SE)의 몇 배만큼 떨어져 있는가”이다.

4.6.3 계산 예시

\(\bar Y = 3.5\), \(\mu_0 = 3\), \(S_Y = 0.75\), N = 9

\[t = \frac{3.5 - 3}{0.75 / \sqrt{9}} = \frac{0.5}{0.25} = 2.00\]

표준오차(SE) = 0.75/3 = 0.25, t값 = 2.00, df = 9 − 1 = 8

4.6.4 결과 해석

JASP 출력 결과:

Statistic df p Mean difference
학교만족도 Student’s t 2.00 8.00 0.081 0.500

p = .081은 유의수준 .05보다 크므로 영가설을 기각하지 못한다. “A대학교 학생들의 학교만족도가 3점과 통계적으로 유의미한 차이가 있다고 볼 수 없다”는 결론이다.

Note

“차이가 없다”는 것을 증명한 게 아니다. “차이가 있다는 충분한 증거를 확보하지 못했다”는 것이다.

APA 보고 형식: 학교만족도의 평균(M = 3.50, SD = 0.75)은 기준점수 3점과 통계적으로 유의미한 차이를 보이지 않았다, t(8) = 2.00, p = .081.

4.6.5 정규성 확인

t검정 실시 전, 정규성 가정을 먼저 확인해야 한다.

  • 방법 1 — Q-Q plot: 데이터 포인트가 대각선(기대되는 정규분포 선)에 가까이 위치하면 정규성 만족
  • 방법 2 — Shapiro-Wilk 검정:
W p
학교만족도 0.910 0.319

p = .319 > .05이므로 정규성 가정 만족(영가설: “정규분포를 따른다”를 기각하지 못함). Shapiro-Wilk에서 p가 크면 정규성 문제가 없다(p가 .05보다 작으면 정규성 위반 의심).

Note

표본이 작을수록(N < 30) Shapiro-Wilk 검정이 특히 중요하다.

4.7 대응표본 t검정 (Paired Samples t-test)

대응표본 t검정은 짝지어진 두 자료의 평균에 차이가 있는지 검정하는 방법이다. 짝지어진 자료의 두 가지 유형은 (1) 같은 대상을 2번 반복 측정(사전검사–사후검사), (2) 짝을 지어 표집(부부 표본, 쌍둥이 표본)이다.

  • 예시 1: 인지행동치료 프로그램 참여 전·후, 우울 척도 점수가 달라졌는가?
  • 예시 2: 부부의 결혼만족도 차이가 있는가? (남편과 아내가 짝으로 묶임)

4.7.1 왜 단일표본 t검정이 아닌가?

사전-사후 비교는 한 집단이지만 두 개의 평균을 비교하는 것이다. 핵심은 “두 측정값 사이의 차이에 의미가 있는가?”를 묻는 것이다. 대응표본 t검정은 실제로 차이점수(D = 사후 − 사전)를 계산하여, 그 차이점수의 평균이 0과 다른지 검정한다. 즉, 내부적으로는 단일표본 t검정과 동일한 논리다.

4.7.2 가설 설정

연구 장면 예시: 100명의 학생이 교육 프로그램에 참여하기 전 사전검사, 참여 후 사후검사를 실시했다. 사전검사 평균 64.80점, 사후검사 평균 71.49점이었다.

  • 영가설(\(H_0\)): 사전검사와 사후검사 점수 평균에 차이가 없다 (\(\mu_{사후-사전} = 0\))
  • 대립가설(\(H_A\)): 사전검사와 사후검사 점수 평균에 차이가 있다 (\(\mu_{사후-사전} \neq 0\))

4.7.3 차이점수(Difference Score)

참여자 사전검사 사후검사 차이점수(D = 사후−사전)
1 80 92 +12
2 33 31 −2
3 55 60 +5
… … … …
100 63 70 +7
평균 64.80 71.49 6.69
표준편차 19.94 15.61 16.30

실질적인 표본 크기는 pair의 수이며 여기서는 100이다.

4.7.4 검정통계량

\[t = \frac{\bar{D} - 0}{S_D / \sqrt{N}}\]

\(\bar D\)는 차이점수의 표본평균(= 사후 평균 − 사전 평균), \(S_D\)는 차이점수의 표본 표준편차, N은 pair의 수이다. 자유도는 df = N − 1이다.

4.7.5 결과 해석

statistic df p Mean difference SE difference
post_test − pre_test 4.10 99.0 < .001 6.69 1.63

t = 4.10, p < .001로 유의수준 .05보다 훨씬 작으므로 영가설을 기각한다. “교육 프로그램 참여 후 사후검사 점수가 사전검사 점수보다 통계적으로 유의미하게 높아졌다”는 결론이다.

APA 보고 형식: 교육 프로그램 참여 후 검사 점수(M = 71.5, SD = 15.6)는 참여 전 검사 점수(M = 64.8, SD = 19.9)보다 유의미하게 높았다, t(99) = 4.10, p < .001, Mean difference = 6.69.

4.7.6 정규성 확인

대응표본 t검정에서는 차이점수(D)의 정규성을 확인한다. Q-Q plot에서 데이터 포인트가 대각선 위에 거의 일치하게 분포하면 정규성 만족이다.

4.8 단일표본 vs 대응표본 t검정 비교

단일표본 t검정 대응표본 t검정
비교 대상 표본 평균 vs 이론적 기준값 짝지어진 두 측정값의 평균 차이
검정하는 것 하나의 표본평균 차이점수(D)의 평균
자유도 N − 1 N − 1 (N = pair 수)
사용 예 학교만족도 평균이 3점과 다른가? 프로그램 전후 점수 차이가 있는가?

4.9 독립표본 t검정 (Independent Samples t-test)

4.9.1 개념

독립표본 t검정(independent samples t-test)은 서로 독립적으로 추출된 두 집단의 모집단 평균에 차이가 있는지 검정하는 방법이다. 두 집단은 서로 관련이 없어야 한다(독립성).

  • 예시 1: 프로그램 참여 여부(참여 vs 비참여)에 따라 협업능력 평균이 다른가?
  • 예시 2: 성별(남 vs 여)에 따라 학업효능감 평균이 다른가?

가설 설정 예시 (협업능력):

  • \(H_0\): \(\mu_{참여} - \mu_{비참여} = 0\) (두 집단의 평균에 차이가 없다)
  • \(H_A\): \(\mu_{참여} - \mu_{비참여} \neq 0\) (두 집단의 평균에 차이가 있다)

4.9.2 검정통계량

\[t = \frac{(\bar{Y}_1 - \bar{Y}_2) - 0}{\sqrt{S_p^2\left(\dfrac{1}{N_1} + \dfrac{1}{N_2}\right)}}\]

분자는 두 집단의 표본 평균 차이(영가설이 참일 때 기대되는 값 0을 뺌), 분모는 표준오차이다. 자유도는 df = \((N_1-1)+(N_2-1) = N_1+N_2-2\)이다.

4.9.3 통합분산 (Pooled Variance, \(S_p^2\))

독립표본 t검정에서는 두 집단의 분산이 모집단에서 같다고 가정(등분산 가정)하고, 두 표본 분산의 가중평균인 통합분산을 사용한다.

\[S_p^2 = \frac{(N_1-1)S_1^2 + (N_2-1)S_2^2}{(N_1-1)+(N_2-1)}\]

각 집단의 자유도를 가중치로 하여 두 표본 분산을 평균한 값이며, 등분산 가정이 충족될 때만 사용 가능하다.

4.9.4 JASP 출력 예시

시나리오: 프로그램 참여 여부(참여 N=40, 비참여 N=60)에 따른 협업능력 차이 검정

Independent Samples T-Test

Statistic df p Mean diff SE diff
협업능력 Student’s t 2.88 98.0 0.005 0.605 0.210

Group Descriptives

Group N Mean SD
참여 40 7.42 1.10
비참여 60 6.82 0.979

t(98) = 2.88, p = .005로 유의수준 .05에서 영가설 기각. 참여집단(M=7.42)이 비참여집단(M=6.82)보다 협업능력이 유의미하게 높다.

4.10 등분산 가정 검토

4.10.1 기본가정 확인

독립표본 t검정을 실시하기 전, 두 가지 기본가정을 확인해야 한다.

  1. 정규성 가정: 각 집단의 데이터가 정규분포를 따르는가 — Q-Q plot으로 확인
  2. 등분산 가정(homogeneity of variance): 두 모집단의 분산이 같은가

4.10.2 Levene’s Test (등분산 가정 검정)

등분산 가정 충족 여부를 확인하기 위해 Levene’s test를 실시한다.

  • \(H_0\): 모집단에서 두 집단의 분산이 같다
  • \(H_A\): 모집단에서 두 집단의 분산이 차이가 있다

Levene’s test의 p값이 유의수준보다 크면 영가설 수용, 즉 등분산 가정 충족을 의미한다.

F df df2 p
협업능력 1.17 1 98 0.282

p = .282 > .05이므로 영가설 수용, 등분산 가정 충족.

4.10.3 등분산 가정을 충족하지 못하는 경우: Welch’s t-test

등분산 가정이 위배될 경우 Welch’s t-test를 사용한다. 두 집단의 분산을 통합하지 않고 각각의 분산을 그대로 사용하며, 자유도 계산 방식도 달라진다(Welch-Satterthwaite 공식). 등분산을 가정한 방법보다 통계적 검정력은 약간 낮다.

\[t = \frac{\bar{Y}_1 - \bar{Y}_2}{\sqrt{\dfrac{S_1^2}{N_1} + \dfrac{S_2^2}{N_2}}}\]

비교 예시:

Statistic df p
Student’s t 2.88 98.0 0.005
Welch’s t 2.82 77.1 0.006

4.11 양방향 검정과 일방향 검정

양방향 검정(two-tailed test, 양측검정)은 차이의 방향을 가정하지 않는 검정이다 (\(H_A: \mu_1 - \mu_2 \neq 0\)). 일방향 검정(one-tailed test, 단측검정)은 차이의 방향을 미리 예측하는 검정이다 (\(H_A: \mu_1 - \mu_2 > 0\) 또는 \(< 0\)).

검정 방향 p값 계산 예시
양방향 양쪽 꼬리 면적의 합 p = .005
일방향 한쪽 꼬리 면적만 p = .002 (= .005 / 2)

일방향 검정은 p값이 작아져 통계적 검정력이 높아지지만, 반대 방향 효과의 가능성을 완전히 배제한다.

Note

일반적으로 양방향 검정을 적용한다(더 보수적, 학계 표준). 효과의 방향에 대해 강한 이론적 근거가 있을 때만 일방향 검정을 적용하며, 데이터를 보고 나서 사후적으로 일방향 검정을 선택하는 것은 부적절하다.

4.12 효과크기 (Effect Size)

4.12.1 p값의 한계

통계적 유의성(p값)만으로는 실제 효과의 크기를 알 수 없다. p값은 효과크기와 표본크기에 동시에 영향을 받으며, 표본이 매우 크면 실제로는 작은 차이도 통계적으로 유의미하게 나타날 수 있다. 따라서 통계적으로 유의할 때(영가설 기각 시), 추가로 효과크기를 보고해야 한다.

4.12.2 Cohen’s d

t검정에서 가장 많이 활용되는 효과크기 지수이다.

Cohen’s d 해석
d = 0.2 작은 효과크기(small effect)
d = 0.5 중간 효과크기(medium effect)
d = 0.8 큰 효과크기(large effect)

계산 공식:

  • 대응표본 t검정: \(\hat d = \dfrac{|\bar D|}{S_D}\) (차이 점수의 평균을 차이 점수의 표준편차로 나눔)
  • 독립표본 t검정: \(\hat d = \dfrac{|\bar Y_1 - \bar Y_2|}{S_p}\) (평균 차이를 통합표준편차로 나눔)

예시: 대응표본 Cohen’s d = 0.410(중간 효과크기), 독립표본 Cohen’s d = 0.589(중간~큰 효과크기)

4.13 신뢰구간 (Confidence Interval)

4.13.1 점추정과 구간추정

점추정(point estimation)은 모집단의 모수치를 단일 값으로 추정한다(예: 표본 평균 72점 → 모집단 평균도 72점일 것이다). 단, 추정의 불확실성을 표현하지 못한다는 단점이 있다.

구간추정(interval estimation)은 오차범위를 고려하여 구간으로 추정한다. 표본 통계치와 모수치가 일치하지 않는 경우가 대다수이므로 오차범위를 고려한 신뢰구간을 활용한다.

4.13.2 95% 신뢰구간의 의미

95% 신뢰구간(confidence interval, CI)은 일정한 사례 수 n을 가진 표집을 무한히 반복추출하여, 표본 통계치 중심으로 신뢰구간을 설정했을 때, 이 중 95%가 모수치를 포함할 것이라 기대되는 구간이다.

Note

“모수치가 신뢰구간 내에 있을 확률이 95%이다”라는 해석은 틀린 표현이다. 모수치는 고정되어 있고, 신뢰구간이 반복추출마다 달라진다. 올바른 해석은 “이런 방식으로 구간을 설정하면, 장기적으로 95%의 구간이 모수치를 포함한다”이다.

4.13.3 신뢰구간을 활용한 가설검정

신뢰구간은 영가설을 수용하는 모수치 범위에 대한 정보를 제공한다.

  • 95% 신뢰구간이 영가설의 모수치(예: 0)를 포함 → 영가설 채택
  • 95% 신뢰구간이 영가설의 모수치를 포함하지 않음 → 영가설 기각

예시 (협업능력 독립표본 t검정):

Statistic df p Mean diff 95% CI Lower 95% CI Upper
2.88 98.0 0.005 0.605 0.189 1.02

95% CI [0.189, 1.02]에 0이 포함되지 않으므로 영가설 기각(p = .005와 일치).

4.14 핵심 요약

  1. t검정: 모집단 표준편차를 모를 때 표본 표준편차로 추정하여 검정
  2. t분포: 자유도(df = N−1)에 따라 모양 변화; df가 클수록 z분포에 근사
  3. 단일표본 t검정: 표본 평균이 특정 기준값과 다른지 검정
  4. 대응표본 t검정: 짝지어진 두 측정값의 차이(D)가 0과 다른지 검정
  5. 독립표본 t검정: 두 독립집단의 평균 차이 검정; 통합분산(\(S_p^2\)) 활용
  6. 등분산 가정: Levene’s test로 확인; 위배 시 Welch’s t-test 사용
  7. 양방향 vs 일방향: 일반적으로 양방향 검정; 강한 이론적 근거가 있을 때만 일방향
  8. 효과크기(Cohen’s d): p값의 한계를 보완; 유의할 때 반드시 보고
  9. 신뢰구간: 구간추정; CI에 0 포함 여부로 가설검정 가능

4.15 R 실습

이 실습은 BDI_data.csv 및 학업심리_data.csv를 이용한 R 실습이다. BDI_data.csv에는 실험/통제 두 집단(변수 집단)의 성별(성별), 사전 우울 문항(BDI_사전_01~BDI_사전_21), 사후 우울 문항(BDI_사후_01~BDI_사후_21)이 들어 있다.

4.15.1 자료 불러오기 및 파생변수 생성

BDI 사전/사후 21개 문항의 합계(총점)와 평균은 rowSums() / rowMeans()로 만들 수 있다.

bdi <- read.csv("BDI_data.csv", fileEncoding = "UTF-8")

# 사전/사후 문항 열 지정
pre_items  <- paste0("BDI_사전_", sprintf("%02d", 1:21))
post_items <- paste0("BDI_사후_", sprintf("%02d", 1:21))

# 파생변수: 총점, 평균
bdi$사전_총점 <- rowSums(bdi[, pre_items])
bdi$사후_총점 <- rowSums(bdi[, post_items])
bdi$사전_평균 <- rowMeans(bdi[, pre_items])
bdi$사후_평균 <- rowMeans(bdi[, post_items])

4.15.2 기술통계

기술통계는 summary(), mean(), sd() 등으로 확인한다.

mean(bdi$사후_총점)
sd(bdi$사후_총점)
summary(bdi$사후_총점)

4.15.3 단일표본 t검정

종속변수 “사후 총점”을 기준값 15와 비교한다.

t.test(bdi$사후_총점, mu = 15)

4.15.4 독립표본 t검정

종속변수 “사후 총점”, 집단변수 “집단”(실험/통제)으로 두 집단의 평균을 비교한다.

t.test(사후_총점 ~ 집단, data = bdi, var.equal = TRUE)   # Student's t (등분산 가정)
t.test(사후_총점 ~ 집단, data = bdi, var.equal = FALSE)  # Welch's t (등분산 미가정)

# 등분산 가정(Levene's test)은 car 패키지의 leveneTest()로 확인 가능
# car::leveneTest(사후_총점 ~ 집단, data = bdi)

4.15.5 대응표본 t검정

“사전 총점”과 “사후 총점”을 짝지어 비교한다.

t.test(bdi$사전_총점, bdi$사후_총점, paired = TRUE)

4.15.6 학업심리 데이터를 활용한 추가 연습

학업심리_data.csv(중·고등학생 200명, GENDER: 1=남학생/2=여학생, SCHOOL: 1=중학교/2=고등학교)를 이용한 연습문제(연습문제_학업심리.md)도 동일한 방식으로 R에서 수행할 수 있다.

aca <- read.csv("학업심리_data.csv", fileEncoding = "UTF-8")

# 1. 빈도분석 (성별, 학교급)
table(aca$GENDER)
table(aca$SCHOOL)

# 2. 학업 자기효능감 점수 생성 (EFFICACY_03, EFFICACY_06은 역채점: 5 - 원점수)
aca$EFFICACY_03_R <- 5 - aca$EFFICACY_03
aca$EFFICACY_06_R <- 5 - aca$EFFICACY_06
efficacy_items <- c("EFFICACY_01","EFFICACY_02","EFFICACY_03_R","EFFICACY_04",
                     "EFFICACY_05","EFFICACY_06_R","EFFICACY_07","EFFICACY_08")
aca$자기효능감 <- rowMeans(aca[, efficacy_items])
mean(aca$자기효능감); sd(aca$자기효능감)

# 3. 학업 스트레스 점수 생성 및 성별 차이 검정
stress_items <- paste0("STRESS_", sprintf("%02d", 1:10))
aca$스트레스 <- rowMeans(aca[, stress_items])
t.test(스트레스 ~ GENDER, data = aca, var.equal = TRUE)

# 4. 학습동기 하위영역 점수 생성
aca$내재동기 <- rowMeans(aca[, c("MOTIV_01","MOTIV_02","MOTIV_03","MOTIV_04")])
aca$외재동기 <- rowMeans(aca[, c("MOTIV_05","MOTIV_06","MOTIV_07","MOTIV_08")])
aca$무동기   <- rowMeans(aca[, c("MOTIV_09","MOTIV_10","MOTIV_11","MOTIV_12")])

# 5. 학습동기 하위영역별 성별 차이 검정
t.test(내재동기 ~ GENDER, data = aca, var.equal = TRUE)
t.test(외재동기 ~ GENDER, data = aca, var.equal = TRUE)
t.test(무동기   ~ GENDER, data = aca, var.equal = TRUE)
