9  회귀분석

9.1 회귀분석이란?

회귀분석(regression analysis)은 하나 이상의 독립변수를 사용하여 종속변수를 설명하거나 예측하는 통계적 방법이다. 독립변수와 종속변수의 관계를 수학적 모형(modeling)으로 표현하고, 모형을 통해 종속변수를 설명하고 예측한다.

독립변수 수에 따른 구분:

  • 독립변수 1개: 단순회귀분석(simple regression)
  • 독립변수 2개 이상: 다중회귀분석(multiple regression)

9.1.1 왜 “회귀”분석인가?

“Regression toward the mean” — 예측값(Y)은 X보다 평균에 더 가까운 값으로 예측된다는 의미에서 유래하였다. 예를 들어, 내담자의 호소 문제 심각도가 평균보다 높을 때, 상담 후 심각도 예측값은 평균 방향으로 수렴하는 경향이 있다.

9.2 단순회귀분석 (Simple Regression)

9.2.1 회귀선

\[\hat{Y} = b_0 + b_1 X\]

  • \(b_0\) (절편, intercept): X가 0일 때 Y의 기대값(예측값)
  • \(b_1\) (기울기, slope): X가 1만큼 변할 때 Y의 예측값이 변하는 정도

9.2.2 최소제곱법 (Least Squares Method, OLS)

데이터를 가장 잘 대표하는 회귀선은 잔차(residual)의 제곱합을 최소화하는 선이다. 잔차 = 실제 관찰된 Y값 − 회귀선이 예측한 Y값

9.2.3 회귀계수 산출

\[b_1 = r_{xy} \cdot \frac{s_Y}{s_X} \qquad b_0 = \bar{Y} - b_1\bar{X}\]

해석:

  • 기울기(\(b_1\)): 독립변수(X)가 1점 더 높으면 종속변수(Y)는 \(b_1\)만큼 더 높게 예측된다
  • 절편(\(b_0\)): 독립변수(X)가 0점일 때 종속변수(Y)는 \(b_0\)로 예측된다

9.2.4 단순회귀분석 실제 예시

예시: 상담 회기 수(X)를 독립변수로, 우울 감소 점수(Y)를 종속변수로 하는 회귀분석 — 상담 회기가 많을수록 우울이 감소하는가?

9.3 회귀분석 결과 해석

9.3.1 비표준화 회귀계수

결과표의 Estimate 열에 해당하며, 원점수 척도에서의 기울기·절편 값이다.

9.3.2 표준화 회귀계수 (β)

X와 Y를 모두 표준화(평균 0, 표준편차 1)한 후 회귀분석을 실시했을 때 산출되는 회귀계수이다.

  • 단순회귀분석에서 표준화 회귀계수 = 상관계수(r)
  • 해석: X점수가 1표준편차 더 높을 때, Y는 β 표준편차만큼 더 높게 예측된다
  • 여러 독립변수들의 상대적 중요도 비교 시 유용

9.3.3 회귀계수의 통계적 유의성 검정

기울기(\(b_1\))에 대한 검정 — 가장 핵심적인 검정

구분 내용
영가설 모집단에서 기울기 값(\(b_1\))이 0이다
대립가설 모집단에서 기울기 값(\(b_1\))이 0이 아니다
판단 p값이 .05보다 작으면 대립가설 채택

참고: 표준오차(SE)와 검정통계량(t)

  • 표준오차(SE): 표집분포의 표준편차 — 표본에 따른 회귀계수의 변동성
  • 검정통계량: \(t = \dfrac{b_1 - 0}{se(b_1)}\), 자유도: N − (독립변수의 수 + 1)인 t분포를 따름

9.3.4 결정계수 \(R^2\)

\[R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}\]

  • SST: 총 변동 (관찰값 − 평균)²의 합
  • SSR: 회귀모형이 설명한 변동
  • SSE: 설명되지 않은 변동(잔차)

해석: 종속변수(Y)의 변동성(분산) 중에서 독립변수(X)(또는 회귀모형)에 의해 설명된 부분의 비율이 __%이다. Adjusted \(R^2\)도 자주 활용된다(독립변수 수가 많을 때 \(R^2\) 과대추정 보정).

9.3.5 Overall Model Test (F검정)

F값이 통계적으로 유의하면 모집단에서 회귀모형이 예측력(설명력)을 가진다는 의미이다. 영가설은 “모든 기울기 회귀계수가 모집단에서 0의 값을 가진다”이며, 모집단에서 \(R^2=0\)인지에 대한 검정으로도 볼 수 있다.

9.4 다중회귀분석 (Multiple Regression)

9.4.1 개념

여러 개의 독립변수를 사용하여 종속변수를 설명 또는 예측한다.

\[\hat{Y} = b_0 + b_1X_1 + b_2X_2 \qquad Y = b_0 + b_1X_1 + b_2X_2 + e\]

핵심 장점: 다른 독립변수들(공변인; covariates)을 통제하고서 관심있는 독립변수의 영향을 확인할 수 있다.

9.4.2 다중회귀분석 결과 해석

비표준화 회귀계수:

  • \(b_0\): 모든 독립변수들의 값이 모두 ’0’일 때의 Y의 예측값
  • \(b_1\): \(X_2\)가 동일한 값을 가지는 상황에서(\(X_2\)가 통제되었을 때), \(X_1\)이 1만큼 더 높을 때 Y의 예측값이 얼마나 더 높은지/낮은지를 의미
  • \(b_2\): \(X_1\)이 동일한 값을 가지는 상황에서(\(X_1\)이 통제되었을 때), \(X_2\)가 1만큼 더 높을 때 Y의 예측값이 얼마나 더 높은지/낮은지를 의미

표준화 회귀계수(β): 모든 변수를 표준화(평균 0, 표준편차 1)한 후 분석했을 때 구해지는 회귀계수로, 독립변수들의 상대적 중요도 비교가 가능하다.

\(R^2\): 종속변수의 분산 중에서 독립변수들 전체에 의해 설명된 비율

9.4.3 다중회귀분석 예시 (상담학)

예시: 상담 회기 수(\(X_1\))와 사회적 지지(\(X_2\))를 독립변수로, 심리적 안녕감(Y)을 종속변수로 하는 회귀분석 — 사회적 지지를 통제한 상태에서 상담 회기 수가 심리적 안녕감을 유의하게 예측하는가?

9.4.4 참고: “통제”의 의미

다중회귀분석에서 \(X_1\)의 회귀계수 \(b_1\)은 다음과 같은 수학적 과정을 거쳐 산출된다.

  1. Y를 \(X_2\)로 회귀분석하여 잔차(\(e_1\)) 계산 → \(X_2\)의 영향을 제거한 Y
  2. \(X_1\)을 \(X_2\)로 회귀분석하여 잔차(\(e_2\)) 계산 → \(X_2\)의 영향을 제거한 \(X_1\)
  3. \(e_1\)과 \(e_2\)의 회귀분석으로 \(b_1\) 산출

\(b_1\)은 “\(X_2\)와 공유하는 분산을 제거한 후” \(X_1\)과 Y의 순수한 관계를 반영한다.

9.5 회귀분석의 가정

회귀분석 실시 전 네 가지 가정을 확인해야 한다: 독립성, 정규성, 선형성, 등분산성. 이를 확인하기 위해 잔차분석(residual analysis)을 실시한다.

9.5.1 다중공선성 (Multicollinearity)

독립변수들 사이에 높은 상관관계가 존재하는 상황이다. 매우 유사한 정보를 제공하는 변수들을 동시에 독립변수로 투입할 때 발생한다.

확인 방법: 공차(tolerance; \(1-R_i^2\)) < 0.1이면 다중공선성 의심, VIF(= 1/tolerance) > 10이면 다중공선성이 존재하는 것으로 판단

9.5.2 이상치 (Outlier) 확인

Cook’s D: 해당 사례를 제외하고 회귀분석을 시행했을 때 회귀계수들(\(b_j\))의 변화를 나타내는 지표. 판단기준: D > 1이면 이상치로 진단

9.6 범주형 독립변수가 포함된 회귀분석

9.6.1 더미코딩 (Dummy Coding)

범주형 변수를 독립변수로 회귀분석에 투입하려면 더미변수(0과 1의 값만 가지는 이분변수)로 변환해서 투입한다.

집단의 개수가 2개인 경우: 한 집단은 0, 다른 집단은 1의 값을 가지도록 변환한다. 상담학 예시로 집단상담 참여 여부(비참여/참여)에서 비참여집단 = 0, 참여집단 = 1로 코딩한다.

더미변수에 대한 기울기 회귀계수의 의미: 두 집단의 종속변수 예측값 차이이며, 0의 값을 가지는 집단보다 1의 값을 가지는 집단이 종속변수의 예측값이 얼마나 더 높은지/낮은지를 의미한다.

집단의 개수가 3개 이상인 경우: 집단 하나를 참조집단(기준집단)으로 정하고, 나머지 집단에 대해 더미변수로 투입한다. ’집단의 수 − 1’개의 더미변수를 투입한다.

상담학 예시: 상담 유형(개인상담/집단상담/온라인상담) — 미참여를 참조집단으로

집단 \(D_1\)(개인) \(D_2\)(집단) \(D_3\)(온라인)
미참여 0 0 0
개인상담 1 0 0
집단상담 0 1 0
온라인상담 0 0 1

회귀식: \(\hat{Y} = b_0 + b_1D_1 + b_2D_2 + b_3D_3\)

각 집단별 예측값: 미참여(참조집단) \(\hat Y = b_0\) / 개인상담 \(\hat Y = b_0+b_1\) / 집단상담 \(\hat Y = b_0+b_2\) / 온라인상담 \(\hat Y = b_0+b_3\)

회귀계수의 의미: \(b_0\)은 참조집단(미참여)의 Y 예측값이며, \(b_1, b_2, b_3\)은 각각 참조집단에 비해 개인상담·집단상담·온라인상담 집단의 종속변수 예측값이 얼마나 더 높은지/낮은지를 나타낸다.

9.6.2 더미변수 해석 시 주의사항

다른 독립변수들이 함께 모형에 투입된 경우, 더미변수의 회귀계수는 다른 변수들이 통제된 상태에서 해당 집단과 참조집단의 Y 예측값 차이를 의미한다.

  • 정확한 해석 예시: “(다른 변수들을) 통제한 상태에서, ○○집단이 참조집단에 비해 Y의 예측값이 △△점 더 높다”
  • 부정확한 해석 예시: “○○집단이 그렇지 않은 집단에 비해 Y의 예측값이 △△점 더 높다” (×)

9.7 회귀분석 핵심 요약

분석 유형 목적 특징
단순회귀 X 1개로 Y 예측 회귀선 기울기·절편 해석
다중회귀 X 2개 이상으로 Y 예측 통제 후 순수 효과 추정
더미코딩 범주형 X 투입 집단수−1개 더미변수 생성

결과 보고 시 필수 정보: 모형 설명량(\(R^2\), Adjusted \(R^2\)), 모형 유의성(F값, p값), 각 예측변수(B(비표준화), β(표준화), t값, p값)

9.8 회귀분석을 활용한 조절효과 분석

9.8.1 매개효과와 조절효과: 개념 구분

매개효과(Mediation Effect)는 독립변수가 제3의 변수(매개변수)를 통해서 종속변수에 미치는 효과이다. 독립변수 → 종속변수 사이의 중간 과정(메커니즘)을 파악하는 데 유용하다. 예시: 상담자 공감 → 작업동맹 → 내담자 증상 감소(“상담자의 공감 수준이 높을수록 작업동맹이 강해지고, 그 결과 내담자의 증상이 더 많이 감소한다”)

조절효과(Moderation Effect)는 독립변수가 종속변수에 미치는 효과가 제3의 변수(조절변수)에 의해 달라지는 효과이다. 독립변수의 효과가 누구에게/어떤 조건에서 더 강하게 나타나는지를 파악한다. 예시: 상담자 공감 → 내담자 증상 감소(내담자 애착유형에 따라 다름) — “상담자의 공감이 증상 감소에 미치는 영향이 안정 애착 내담자와 불안 애착 내담자 간에 다르게 나타난다”

Note

핵심 구분: 매개효과 = 경로(how/why) 파악 / 조절효과 = 조건(when/for whom) 파악

9.8.2 조절효과 분석방법

9.8.2.1 조절효과의 개념

조절효과는 상호작용효과(interaction effect)와 동일한 개념이다. \(X_2\)의 값에 따라 \(X_1\)이 Y에 미치는 영향이 달라진다면 \(X_1\)과 Y의 관계에서 \(X_2\)의 조절효과가 있는 것이며, \(X_1\)이 Y에 미치는 효과의 방향이나 크기를 \(X_2\)가 조절한다는 의미이다.

9.8.2.2 모형 설계방법

원 변수(\(X_1, X_2\))와 함께, 두 변수의 곱(\(X_1 \times X_2\))으로 새로운 변수를 생성하여 함께 독립변수로 투입한다.

\[\hat{Y} = b_0 + b_1X_1 + b_2X_2 + b_3(X_1 \times X_2) = (b_0 + b_2X_2) + (b_1 + b_3X_2)X_1\]

해석 예시:

\(X_2\) 값 회귀식 \(X_1\)의 기울기
\(X_2 = 0\) \(\hat Y = b_0 + b_1X_1\) \(b_1\)
\(X_2 = 1\) \(\hat Y = (b_0+b_2) + (b_1+b_3)X_1\) \(b_1+b_3\)
\(X_2 = 2\) \(\hat Y = (b_0+2b_2) + (b_1+2b_3)X_1\) \(b_1+2b_3\)

\(X_2\)가 1 증가할 때마다 \(X_1\)이 Y에 미치는 영향력이 \(b_3\)만큼 변화한다. \(b_3\)가 통계적으로 유의하면 조절효과가 존재하는 것이다.

변수 처리 권장사항: 연속변수는 centering(평균을 빼서 편차점수로 변환) 후 투입하여 다중공선성을 감소시키고 절편 해석 가능성을 확보한다. 범주변수는 더미변수로 변환 후 투입한다.

Note

독립변수와 조절변수의 구분은 통계적으로 결정되는 것이 아니라, 연구자의 이론적 틀에 따라 해석하는 것이다. X와 M의 위치가 바뀌어도 모형 설계방법은 동일하다.

9.8.3 조절효과 분석의 실제

9.8.3.1 예시 1: 연속변수 조절 (두 연속변수의 상호작용)

연구문제: 상담자의 공감 수준이 내담자의 우울 감소에 미치는 영향이 내담자의 사회적 지지 수준에 따라 다르게 나타나는가?

  • 독립변수(X): 상담자 공감(CounselorEmpathy)
  • 조절변수(M): 사회적 지지(SocialSupport)
  • 종속변수(Y): 우울 감소(DepressionReduction)
  • 모든 연속변수는 centering 처리 후 투입

회귀분석 결과:

Predictor Estimate SE t p
Intercept 3.385 0.062 54.877 <.001
CounselorEmpathy_centering 0.354 0.082 4.326 <.001
SocialSupport_centering 0.330 0.082 4.010 <.001
CounselorEmpathy × SocialSupport 0.308 0.102 3.029 .003

계수 해석:

  1. 상담자 공감(b = 0.354): 사회적 지지가 평균수준인 내담자의 경우, 상담자 공감이 1점 더 높으면 우울 감소 점수가 0.354점 더 높게 예측됨(centering을 했기 때문에 절편은 두 예측변수가 모두 평균인 시점의 예측값)
  2. 사회적 지지(b = 0.330): 상담자 공감이 평균수준일 때, 사회적 지지가 1점 더 높으면 우울 감소 점수가 0.330점 더 높게 예측됨
  3. 상호작용항(b = 0.308, p = .003): 통계적으로 유의함. 사회적 지지가 높을수록 ’상담자 공감에 따른 우울 감소 예측값의 변화량’이 더 커진다. 사회적 지지가 1점 더 높을수록, 상담자 공감→우울 감소 기울기가 0.308만큼 커진다. 즉, 사회적 지지가 높은 내담자에게서 상담자 공감이 우울 감소에 미치는 효과가 더 강하게 나타난다.

9.8.3.2 예시 2: 범주변수 조절 (연속변수 × 더미변수 상호작용)

연구문제: 집단상담 참여/비참여 집단에서 상담 회기 수에 따른 심리적 안녕감 변화가 다르게 나타나는가?

  • 독립변수(X): 상담 회기 수(SessionCount)
  • 조절변수(M): 집단상담 참여 여부(GroupCounseling: yes/no → 더미변수)
  • 종속변수(Y): 심리적 안녕감(WellBeing)
  • SessionCount는 centering 처리, GroupCounseling은 더미코딩(no=0, yes=1)

회귀분석 결과:

Predictor Estimate SE t p
Intercept 52.159 1.175 44.395 <.001
SessionCount_centering 1.112 0.242 4.600 <.001
GroupCounseling: yes – no 4.420 1.718 2.572 .010
SessionCount × GroupCounseling (yes–no) 0.846 0.376 2.250 .025

참조 집단: 비참여(no)

계수 해석:

  • 상담 회기 수(b = 1.112): 집단상담 비참여 내담자의 경우, 회기가 1회 증가할 때마다 심리적 안녕감이 1.112점 증가
  • 집단상담 참여(b = 4.420): 회기 수가 평균일 때 집단상담 참여 집단이 비참여 집단보다 심리적 안녕감이 4.420점 높음
  • 상호작용(b = 0.846, p = .025): 집단상담 참여 집단에서 회기 수의 기울기가 비참여 집단보다 0.846 더 크다(비참여 집단의 기울기: 1.112, 집단상담 참여 집단의 기울기: 1.112 + 0.846 = 1.958). 즉, 집단상담을 병행하는 경우 회기를 거듭할수록 심리적 안녕감이 훨씬 빠르게 향상된다.

9.8.4 참고: 매개효과 분석방법

9.8.4.1 효과의 구분

독립변수(X)가 종속변수(Y)에 미치는 효과는 세 가지로 구분된다: X→Y 직접효과 = c, X→Y 매개효과(간접효과) = X→M→Y = \(a \times b\), X→Y 총 효과 = 직접효과 + 매개효과 = \(c + a\times b\)

9.8.4.2 완전매개와 부분매개

유형 조건 의미
완전매개 매개효과만 유의, 직접효과(c) 비유의 X가 Y에 미치는 영향이 전적으로 M을 통해서만 나타남
부분매개 매개효과와 직접효과(c) 모두 유의 X가 Y에 직접적으로도 영향을 미치며, M을 통한 경로도 유의

9.8.4.3 Baron & Kenny (1986) 방법

3번의 회귀분석을 통해 매개효과를 검증한다.

  • Step 1: X → Y 회귀분석 → 총 효과(\(c+a\times b\)) 유의성 확인
  • Step 2: X → M 회귀분석 → 경로 a 유의성 확인
  • Step 3: X, M → Y 회귀분석 → 경로 b와 직접효과 c 유의성 확인
Note

총 효과가 유의하지 않더라도, 직접효과와 간접효과의 방향이 반대인 경우 매개효과와 직접효과가 모두 유의미할 수 있다(억제 효과, suppression).

9.8.4.4 매개효과 크기 계산 (Tracing Rule)

매개효과의 크기 = 해당 경로 회귀계수들의 곱: \((X\to M) \times (M\to Y) = a \times b\)

9.8.4.5 매개효과의 통계적 유의성 검정

방법 1: Sobel Test — 매개효과(\(a\times b\))의 표준오차를 공식으로 계산:

\[Z_{ab} = \frac{a \times b}{\sqrt{a^2 \times se_b^2 + b^2 \times se_a^2}}\]

비교적 간단하나, 매개효과 분포가 정규분포를 따른다는 가정이 필요하다. 실제로 회귀계수의 곱은 편포를 이루는 경우가 많아 한계가 있다.

방법 2: 부트스트랩(Bootstrapping) 방법 — 현재 권장: 표본자료로부터 반복 표집(통상 1000~5000회)을 통해 분포를 경험적으로 생성한다. 정규분포 가정이 불필요하여 더 정확한 신뢰구간을 제공한다. 95% 신뢰구간에 0이 포함되지 않으면 매개효과가 통계적으로 유의하다.

분석 예시: Predictor(X): CounselorEmpathy, Mediator(M): TherapeuticAlliance, Outcome(Y): SymptomReduction, Bootstrap 1000 samples

Effect Label Estimate SE Lower Upper % Mediation
Indirect \(a \times b\) 0.226 0.016 0.195 0.256 70.440
Direct c 0.095 0.021 0.054 0.135 29.560
Total \(c + a\times b\) 0.320 0.024 0.274 0.369 100.000

예시: 외상 경험→인지적 왜곡→심리적 고통 — a(외상 경험→인지적 왜곡) = 0.337, b(인지적 왜곡→심리적 고통) = 0.669, 매개효과 = 0.226(95% CI [0.195, 0.256], 0 미포함 → 유의). 부분매개: 직접효과(c=0.095)도 유의하므로 외상이 인지적 왜곡을 통해 심리적 고통을 증가시키는 경로 외에, 직접적인 영향도 존재한다.

9.10 R 실습

이 실습은 counseling_practice_data.csv(상담학 실습 데이터, counseling_practice_data_codebook.md 및 실습예제.html 참고)를 이용한 회귀분석 R 실습이다.

9.10.1 단순회귀분석

종속변수(Dependent Variable) = CounselingEffects(상담 효과), 설명변수(Covariate) = CounselorEmpathy(상담자 공감)로 지정한다. 이는 실습예제.html의 Week 10–11 예제 1(“상담자 공감(CounselorEmpathy)은 상담 효과(CounselingEffects)를 유의하게 예측하는가?”)과 일치한다.

dat <- read.csv("counseling_practice_data.csv")

fit_simple <- lm(CounselingEffects ~ CounselorEmpathy, data = dat)
summary(fit_simple)   # 회귀계수(b), 표준오차, t값, p값, R^2, F검정 확인

9.10.2 다중회귀분석

종속변수(Dependent Variable) = CounselingEffects, 설명변수(Covariates) = CounselorEmpathy, SocialSupport, TherapeuticAlliance, Depression으로 지정하고, 다중공선성(Collinearity statistics, VIF)을 함께 확인한다.

fit_multi <- lm(CounselingEffects ~ CounselorEmpathy + SocialSupport +
                   TherapeuticAlliance + Depression, data = dat)
summary(fit_multi)

9.10.3 조절효과 분석 (연속변수 × 연속변수)

실습예제.html의 Week 12 예제 1은 CounselorEmpathy(centering)와 SocialSupport(centering)의 상호작용이 CounselingEffects를 예측하는지 검증한다.

dat$CounselorEmpathy_c <- dat$CounselorEmpathy - mean(dat$CounselorEmpathy)
dat$SocialSupport_c    <- dat$SocialSupport - mean(dat$SocialSupport)

fit_mod <- lm(CounselingEffects ~ CounselorEmpathy_c * SocialSupport_c, data = dat)
summary(fit_mod)   # 상호작용항(CounselorEmpathy_c:SocialSupport_c)의 b, t, p 확인

9.10.4 조절효과 분석 (연속변수 × 범주변수)

실습예제.html의 Week 12 예제 2는 상담 회기 수(Sessions, centering)와 상담 유형(CounselingType, 더미코딩: 집단=1/개인=0)의 상호작용이 상담 효과를 예측하는지 검증한다.

dat$Sessions_c <- dat$Sessions - mean(dat$Sessions)
dat$Group_dummy <- ifelse(dat$CounselingType == 2, 1, 0)  # 집단상담=1, 개인상담=0

fit_mod2 <- lm(CounselingEffects ~ Sessions_c * Group_dummy, data = dat)
summary(fit_mod2)
Note

매개효과(부트스트랩) 분석은 기본 R 함수만으로는 수행이 어려워(별도 패키지 mediation, lavaan 등이 필요) 이번 실습에는 포함하지 않았다.
