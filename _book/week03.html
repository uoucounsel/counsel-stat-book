2  자료의 기술

2.1 자료 보여주기

2.1.1 왜 자료를 ’요약’해야 하는가?

아래 숫자들을 보자.

75  89  57  88  61  54
90  79  91  69  99  80
83  76  45  87  63  42
23  98  67  54  34  54
87  91  93  64  56  37

이 숫자들에서 어떤 특징을 읽어낼 수 있는가? 어렵다. 숫자가 많아질수록 그냥 나열된 자료만으로는 전체적인 경향을 파악하기가 거의 불가능하다.

자료의 특징을 효과적으로 ’요약’하여 보여주는 것이 기술통계의 목적이다.

목적 질문 예시
기술통계 주어진 자료를 요약하여 보여주기 “이 반 학생들의 평균 점수는 얼마인가?”
추리통계 표본으로 모집단의 특징을 추론·일반화 “이 프로그램이 효과가 있는가?”

자료를 요약하는 방법은 크게 두 가지이다.

  • 표나 그래프로 보여주기 — 빈도분포표, 막대그래프, 히스토그램, 상자그림
  • 숫자로 보여주기 — 평균, 표준편차, 왜도, 첨도 등

2.2 표와 그래프

2.2.1 빈도분포표 (frequency table)

변수 값이 얼마나 자주 나타나는지(빈도, 비율)를 정리한 표이다.

  • 범주변수에 주로 활용 (예: 성별, 학년, 집단)
  • 연속변수는 구간으로 묶어서 활용

예시: 상담 참여자의 성별 분포

구분 빈도(명) 전체 비율 누적 비율
남학생 56 44% 44%
여학생 70 56% 100%
Note

설문조사에서 응답자의 인구통계학적 특성(성별, 연령대, 학년 등)을 보고할 때 빈도분포표를 기본적으로 사용한다.

2.2.2 막대그래프 (bar plot)

범주변수의 빈도분포를 막대로 시각화한 것이다. 빈도분포표의 내용을 눈으로 바로 비교할 수 있게 해준다. 막대의 높이는 빈도(또는 비율)를 나타내며, 범주 간 차이를 한눈에 확인할 수 있다.

2.2.3 히스토그램 (histogram)

연속변수의 분포를 시각화한 것이다. 막대그래프와 비슷해 보이지만, 연속적인 수치 데이터를 구간으로 나눠 빈도를 표현한다.

  • 막대그래프: 범주변수 (성별, 집단 등)
  • 히스토그램: 연속변수 (점수, 나이, 소득 등)

히스토그램의 핵심 활용은 분포의 모양을 확인하는 것이다. 본격적인 통계분석 전, 데이터가 정규분포(종 모양, 좌우대칭)에 가까운지를 확인하는 것이 중요하다. 많은 통계 기법이 정규분포를 가정하기 때문이다.

  • 성취도 점수 히스토그램 → 종 모양에 가까움 (정규분포에 근접)
  • 소득 히스토그램 → 오른쪽으로 긴 꼬리 (소수의 고소득자로 인한 편포)
Note

우울척도(PHQ-9) 점수를 수집했다면, 분석 전 히스토그램으로 분포 형태를 확인해야 한다. 상담을 받지 않는 일반 집단은 대부분 낮은 점수에 몰려 있어 정적편포를 보이는 경우가 많다.

2.2.4 상자그림 (box-plot, 상자도표)

다섯 가지 수치를 이용해 자료를 요약하는 그래프이다. 특히 집단 간 비교와 이상치 탐색에 탁월하다.

상자그림은 아래로부터 최솟값(이상치 제외), 제1사분위수(Q1, 25백분위수), 중앙값(50백분위수), 제3사분위수(Q3, 75백분위수), 최댓값(이상치 제외) 순으로 구성되며, 범위를 벗어난 값은 이상치로 별도 표시한다.

  • IQR(사분위수 범위): Q3 - Q1 → 중간 50% 자료가 퍼진 범위
  • 이상치(outlier): IQR의 1.5배를 벗어난 값 → 그래프에 점(○)으로 표시
Note

읍면 지역 vs 도시 지역 학생의 성취도 상자그림을 비교하면, 도시 지역 학생의 중앙값이 더 높고 도시 지역에 이상치(특별히 낮은 점수를 받은 학생)가 존재하며, 두 집단의 분포 범위(IQR)도 비교할 수 있다.

2.3 수치를 통한 자료의 요약

자료의 특징을 숫자 하나로 표현하는 방법은 크게 중심과 퍼짐으로 나뉜다.

2.3.1 자료의 중심 (중심 경향치)

2.3.1.1 평균 (mean)

\[\bar{Y} = \frac{Y_1 + Y_2 + \cdots + Y_n}{n} = \frac{1}{n}\sum_{i=1}^{n} Y_i\]

모든 값을 더한 후 사례 수로 나눈다.

예시: 5명의 상담회기 수가 [3, 5, 6, 8, 8]이라면

\[\bar{Y} = \frac{3+5+6+8+8}{5} = \frac{30}{5} = 6\]

모든 사례의 값을 사용하므로 정보 손실이 없고 가장 널리 사용되지만, 극단값(이상치)에 민감하다는 단점이 있다.

2.3.1.2 중앙값 (median)

자료를 크기 순으로 나열했을 때 가운데 위치하는 값이다. 사례 수가 홀수이면 정확히 가운데 값, 짝수이면 가운데 두 값의 평균이다.

이상치의 영향 비교:

자료 평균 중앙값
40, 45, 50, 55, 60 50 50
40, 45, 50, 55, 100 58 (올라감) 50 (그대로)
Note

소득, 집값처럼 소수의 극단값이 존재하는 변수에는 평균보다 중앙값이 더 대표값으로 적합하다. “대한민국 1인 가구 평균 소득”이라고 하면 일부 고소득자 때문에 실제 체감과 다를 수 있는데, 이때 중앙값이 더 현실적인 대표값이다.

2.3.1.3 최빈값 (mode)

가장 많이 관찰된 값이다. 빈도가 가장 높은 값이며 범주형 자료에 주로 사용된다. 예: “이 집단에서 가장 흔한 상담 유형은?” → 최빈값으로 답할 수 있음.

2.3.2 자료의 퍼짐 (변산성, variability)

중심 경향치만으로는 자료를 충분히 설명할 수 없다. 예를 들어 두 반의 시험 점수 평균이 모두 70점이라도:

  • A반: [68, 69, 70, 71, 72] → 평균 70, 비슷비슷함
  • B반: [30, 50, 70, 90, 100] → 평균 70, 매우 다양함

두 반의 차이를 설명하려면 퍼짐의 정도가 필요하다.

2.3.2.1 범위 (range)

\[\text{범위} = \text{최댓값} - \text{최솟값}\]

  • A반: 72 - 68 = 4
  • B반: 100 - 30 = 70

계산이 간단하지만, 이상치 하나로 크게 달라져 정보가 제한적이다.

2.3.2.2 편차 (deviation)

\[\text{편차}_i = Y_i - \bar{Y}\]

각 점수가 평균에서 얼마나 떨어져 있는지를 나타낸다.

예시: 평균이 60점인 집단에서

학생 점수(Y) 평균(Ȳ) 편차(Y-Ȳ)
1 30 60 -30
2 45 60 -15
3 51 60 -9
4 78 60 +18
5 96 60 +36
합계 0
Note

편차의 합은 항상 0이다. 그래서 편차의 합으로는 퍼짐을 측정할 수 없다.

2.3.2.3 분산 (variance)

편차가 양수/음수로 상쇄되는 문제를 해결하기 위해 편차를 제곱한 후 평균을 낸다.

\[S^2 = \frac{\sum(Y_i - \bar{Y})^2}{n-1}\]

예시 (위 자료 계속):

학생 편차 편차²
1 -30 900
2 -15 225
3 -9 81
4 +18 324
5 +36 1296
합계 0 2826

\[S^2 = \frac{2826}{5-1} = \frac{2826}{4} = 706.5\]

2.3.2.4 표준편차 (standard deviation, SD)

분산은 단위가 제곱되어 있어서 해석이 어렵다. 예를 들어 점수의 분산은 “점수²” 단위가 된다. 이를 원래 단위로 되돌리기 위해 제곱근을 취한다.

\[SD = S = \sqrt{S^2} = \sqrt{\frac{\sum(Y_i - \bar{Y})^2}{n-1}}\]

표준편차는 “각 점수가 평균으로부터 평균적으로 얼마나 떨어져 있는가”를 나타낸다. SD = 13이라면 “대부분의 사람들이 평균에서 약 ±13점 범위 안에 있다”고 해석할 수 있다.

Note

“이 집단의 우울점수 평균은 15점(SD=5)이었다” → 대부분의 참여자 점수가 10~20점 사이에 분포함을 의미한다.

2.3.3 모집단 분산과 표본 분산

모집단 분산 표본 분산
기호 \(\sigma^2_Y\) \(S^2_Y\)
분모 \(n\) \(n-1\)
공식 \(\sum(Y_i-\mu_Y)^2/n\) \(\sum(Y_i-\bar{Y})^2/(n-1)\)

왜 표본 분산은 n-1로 나누는가?

표본의 편차를 계산할 때 우리는 모집단 평균(\(\mu\)) 대신 표본 평균(\(\bar Y\))을 사용한다. 그런데 표본 평균 자체가 이미 표본 자료에 맞추어 계산된 것이기 때문에, 편차가 실제보다 작게 계산되는 경향이 있다. 표본 평균을 이미 한 번 ’사용’했기 때문에, 독립적으로 자유롭게 움직일 수 있는 값이 n개가 아니라 n-1개가 된다.

예시로 이해하기: 5명의 점수가 있고 평균이 50이라는 것을 안다고 하자. 4명의 점수가 [40, 45, 55, 60]이라면, 마지막 1명의 점수는 반드시 50이어야 한다. 즉, n=5이지만 자유롭게 변할 수 있는 정보는 4개(n-1)뿐이다. 이것이 자유도(degree of freedom; df) = n-1의 의미다.

2.3.3.1 자유도 (degree of freedom; df)

  • 모집단을 추론하기 위해 사용할 수 있는 독립적인 정보의 개수
  • 표본 분산 계산 시: df = n-1
  • n-1로 나누어야 모집단 분산을 과소추정하지 않는, 불편 추정량(unbiased estimator)이 된다

2.3.4 왜도와 첨도

분포의 모양을 수치로 나타내는 지수이다.

2.3.4.1 왜도 (skewness): 분포가 어느 쪽으로 치우쳐 있는가?

왜도 분포 모양 설명
왜도 > 0 정적편포 오른쪽으로 긴 꼬리. 대부분 낮은 값, 소수의 높은 값
왜도 = 0 좌우대칭 정규분포
왜도 < 0 부적편포 왼쪽으로 긴 꼬리. 대부분 높은 값, 소수의 낮은 값
  • 소득 분포 → 정적편포 (왜도 > 0): 대부분 낮은 소득이지만 소수의 억만장자가 오른쪽 꼬리를 만든다
  • 천장효과(ceiling effect)가 있는 쉬운 시험 점수 → 부적편포 (왜도 < 0): 대부분 높은 점수
Note

일반적으로 |왜도| < 2 이면 정규분포에 충분히 가깝다고 판단한다.

2.3.4.2 첨도 (kurtosis): 분포가 얼마나 뾰족한가?

첨도 분포 모양 설명
첨도 > 0 뾰족한 분포 중심에 더 많이 몰려있고, 꼬리가 두꺼움
첨도 = 0 정규분포 (일부 소프트웨어에서는 첨도=3으로 표시)
첨도 < 0 평평한 분포 값들이 전반적으로 고르게 퍼져 있음
Note

일반적으로 |첨도| < 10 이면 분석에 큰 문제 없다고 판단한다.

2.3.5 기술통계 분석 예시

기술통계 분석을 실행하면 다음과 같은 출력을 얻을 수 있다.

예시 출력: 성취도점수 (N=200)

항목 값 해석
N 200 유효 사례 수 200명
Missing 0 결측값 없음
Mean 69.505 평균 약 70점
Median 70.000 중앙값 70점 → 평균≈중앙값, 편포 적음
Standard deviation 13.073 평균에서 평균 ±13점 범위
Variance 170.915 SD의 제곱
Minimum 33 최솟값
Maximum 95 최댓값
Skewness -0.386 약한 부적편포, 정규분포에 가까움
Kurtosis -0.256 약간 평평한 분포, 정규분포에 가까움
Note

이 자료는 평균(69.5)과 중앙값(70)이 거의 같고, 왜도와 첨도 모두 절대값이 작아 정규분포에 근접한다. 이후 모수통계 분석(t검정, 회귀분석 등)을 사용하기에 적합하다.

2.3.6 자료의 변환

수집된 자료에 수학적 변환을 가했을 때 평균과 표준편차는 어떻게 변할까?

상수를 더하거나 빼는 경우: 모든 학생 점수에 5점을 더해준다면, 평균은 70 → 75(5만큼 이동)로 변하지만 표준편차는 13 → 13(그대로)이고 분포 형태도 변하지 않는다. 전체 점수를 위로 올리면 중심은 이동하지만, 학생들 사이의 상대적인 차이는 그대로다.

상수를 곱하거나 나누는 경우: 모든 점수에 2를 곱한다면, 평균은 70 → 140(2배), 표준편차는 13 → 26(2배)으로 변하지만 분포 형태는 변하지 않는다. 전체를 늘리면 중심과 퍼짐이 모두 변하지만, 분포의 모양(비대칭 정도)은 바뀌지 않는다.

분포의 형태 자체를 바꾸려면? — 로그변환: 소득, 반응시간처럼 극단적으로 편포된 변수는 그대로 사용하면 정규분포 가정을 위반할 수 있다. 로그변환(\(Y \to \ln(Y)\))은 정적편포(오른쪽 꼬리)를 좌우대칭에 가깝게 만들어 주고, 극단적으로 큰 값들의 영향을 줄여준다.

예시: 소득 데이터

통계량 원래 소득 로그변환 후
평균 300 5.53
SD 217 0.596
왜도 5.02 -0.362

왜도가 5.02 → -0.362로 크게 감소하여 정규분포에 훨씬 가까워진다.

Note

로그변환 후 결과를 해석할 때는 변환된 단위(ln 값)로 해석하거나, 다시 지수변환(\(e^{값}\))으로 되돌려 원래 단위로 해석해야 한다.

Note

자주 하는 질문

  • 평균과 중앙값 중 어떤 것을 써야 하나요? 이상치가 없거나 적은 대칭 분포에서는 평균, 이상치가 있거나 심하게 편포된 분포에서는 중앙값이 더 대표값으로 적합하다.
  • 표준편차는 크면 나쁜 건가요? 아니다. 표준편차는 단순히 자료가 얼마나 퍼져 있는지를 나타낼 뿐이며, 연구 목적에 따라 퍼짐이 클 수도 작을 수도 있다.
  • 왜도가 ±2를 넘으면 어떻게 해야 하나요? 로그변환, 제곱근 변환 등을 고려하거나, 정규분포를 가정하지 않는 비모수 통계 방법을 사용한다.
  • 첨도가 3으로 나오는 소프트웨어도 있던데요? 소프트웨어마다 첨도 계산 방식이 다르다. 정규분포의 첨도를 0으로 기준 삼는 경우도 있고, 일부 소프트웨어(예: SPSS 구버전)는 3을 기준으로 삼는다. 해석 시 어떤 기준인지 확인해야 한다.
